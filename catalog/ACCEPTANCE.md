# 物理参数库与安全公式入口：独立验收计划

本文件定义验收标准，不预先宣称实现已通过。执行时记录版本、运行命令、结果与未覆盖项；不得把未执行的浏览器人工检查写成通过。测试应针对外部可观察行为，并使用独立解析值核对单位和导数，避免仅复述解释器实现。

## A. 数据与作用域

| 编号 | 操作 | 应有结果 |
| --- | --- | --- |
| A1 | 加载内置目录，逐个验证模板规格 | 参数/单位/分类引用有效；模板可独立生成残差；演示值有明确标识 |
| A2 | 给定义添加材料名称但不填写数值 | 不把定义推断成真实材料常数；运行前拒绝未定值 |
| A3 | 修改物理参数，随后切换学习率/训练方法 | 物理值与训练配置各自保持预期状态，不互相覆盖 |
| A4 | 导入冲突 id、未知单位；向方程加入重复符号 | 明确拒绝并指出原因，不覆盖已有定义。完全相同定义可复用；库中不同定义允许相同建议符号，方程内部不允许 |
| A5 | 参数值设为字符串、布尔值、NaN/Infinity 或超出实现允许范围的值 | 拒绝非法值；有限数值的允许范围与实际校验一致 |
| A6 | 修改同一加载结果后重新加载内置目录 | 新加载结果不因上次调用对返回对象的修改而被污染 |

## B. 安全公式与维度

| 编号 | 操作 | 应有结果 |
| --- | --- | --- |
| B1 | 未知场改名，公式使用新的字段名 | 生成残差引用正确单场；旧字段名成为未定义标识符 |
| B2 | 1D 使用 y/dy，静态使用 t/dt | Python 与前端均拒绝，不能只在训练时才失败 |
| B3 | 二阶空间和混合导数；三阶嵌套；二阶时间导数 | 合法二阶空间导数可用；超阶及 dt(dt(...)) 拒绝 |
| B4 | 输入属性访问、索引、赋值、lambda、模块导入、未知调用、任意脚本内容 | 不执行输入；拒绝不支持语法，旧工程状态保留 |
| B5 | 输入原型相关键、异常层深或特别长的表达式/包 | 不污染原型/状态；错误可控，不冻结界面；若尚无限额则记为未覆盖风险 |
| B6 | 同量纲相加、不同量纲相加、量纲不合要求的函数入参 | 合法表达式通过，其余报出具体错误 |
| B7 | 把连续变系数放在导数内，与放在导数外比较 | 使用解析场验证乘积求导项；不把坐标系数当常数 |
| B8 | 式子合法但运行值含除零或函数定义域错误 | 不把语法通过写成数值成功；运行异常/非有限值被现有训练检查识别 |

## C. 单位与独立解析对照

以物理压力场 `p_SI = x_SI² + 3 y_SI² + 2 t_SI` 为独立解析例子，并给系数赋予相应量纲。令网络返回 `p_raw = p_SI / field_factor`，不要用被测残差构建预期值。

1. SI 坐标下验证空间导数为 `2*x_SI`、`6*y_SI`，二阶空间导数为 `2`、`6`，时间导数为 `2`。
2. 分别以 cm、mm 描述同一空间点，以 day、year 描述同一时间点，以 kPa 描述同一压力，比较转换后的导数和残差；应与 SI 案例相等。year 的秒数必须与内置明确约定一致。
3. 对 `D` 使用 `m^2/year` 与等值 `m^2/s`，在压力扩散残差中获得相同值。不能只测试单位标签变换，也不能只测试参数乘 factor 而漏测坐标求导。
4. 验证 x/y 单位不一致被拒绝；无支持的单位和带温标偏移的单位不能被误当乘法单位。
5. 手动把同一几何从 `1 m` 改为 `100 cm` 应等价；仅把单位 m 改成 cm 而保持数值 1 时，应按物理尺寸改变处理，不静默重缩放几何。
6. 使用 `dx(k0 * (1 + x/L) * dx(p))` 验证坐标参与的变系数与单位一致，参数常数仍只有一次 SI 换算。
7. 对残差做反向传播，验证导数和换算后仍能传递梯度；同时记录残差 SI 尺度和边界原始场单位尺度，不能声称自动无量纲化。

## D. 导入事务与离线迁移

每次失败用例均在导入前记录公式、参数、单位、库记录、代码输出和几何/边界设置；失败后逐项比较。

| 编号 | 操作 | 应有结果 |
| --- | --- | --- |
| D1 | 导入有效参数包，选择自定义参数并填写数值 | 参数可搜索/选用；材料记录保持其数据身份 |
| D2 | 包的最后一条记录有错，前面若干条有效 | 整包失败，所有导入前状态保持不变，不留下部分定义 |
| D3 | 包带 units、templates、代码或未知版本 | 明确拒绝，不执行内容，不更新当前目录 |
| D4 | 导出当前方程，在全新页面导入 | 公式、参数、未知场和单位等价；几何/边界不宣称已恢复 |
| D5 | 工程 AST 与 expression_source 不一致或含未定义参数 | 校验明确处理冲突，不能显示一种公式却运行另一种公式 |
| D6 | 导出只含本地自定义参数的方程，移走原参数包 | 工程可重新载入；生成 Python 仅凭嵌入 spec 与兼容 OpenPINN 可构建残差 |
| D7 | 在无网络页面完成目录使用、导入、导出与代码生成 | 不需要 CDN/远端服务；不出现自动上传请求 |
| D8 | 多次导入同一包以及与已有参数冲突的包 | 行为明确，不悄悄覆盖值；失败时保留旧状态 |
| D9 | 模板应用与当前问题结构不一致 | 不默改几何/边界；要求用户处理维度/类型冲突或清晰说明结果 |

## E. 集成与发布

- 在配置器中生成压力扩散、稳态 Darcy、热扩散代码，分别编译、构建问题并做少量训练步，检查有限残差和必要输出；不以短跑代替精度验证。
- 对单场适用性报告检查其维度和静态/动态元数据。不要把 Biot、多变量或二阶时间问题误报为当前入口完整支持。
- 针对旧“自由组合”与新安全公式入口各做一次回归，确认新功能不改变旧模板和已有训练参数。
- 测试 Neumann/Robin 仍是现有导数语义；模板不得把通量参数当成外法向导数值自动填入。
- 在隔离环境安装新构建的 wheel，确认内置 `physics_catalog.json` 包含在安装包内，运行 `load_physics_catalog()` 与单个残差解析对照。
- 执行相关 Python 测试与 `npm test`；再运行 `python scripts/build_docs.py`，检查新文档可导航、离线资源完整、构建产物已更新。
- 对实际浏览器进行键盘操作、输入错误提示、文件导入/下载、参数长列表和窄窗口检查。DOM 单测无法替代这些人工检查。
