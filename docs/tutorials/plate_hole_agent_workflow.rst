带孔板平面应力：五 Agent 诊断闭环
==================================

.. admonition:: 结果状态：预印本结果

   本页过程和数字来自随项目提供的 OpenPINN/PINO 预印本第 5.3 节。仓库已有带孔板规范、
   短运行脚本与 notebook，但尚未提交预印本中的 FEM 探针、三随机种正式训练和全部诊断产物。

工程问题
--------

边长 2 m 的方板中心有半径 0.25 m 的圆孔。材料为平面应力各向同性弹性体，
:math:`E=210` GPa、:math:`\nu=0.3`。左边固定，右边施加 1 MPa 水平拉力，上下边及孔壁
无牵引，未知场为 :math:`u_x,u_y`。FEM 探针仅用于训练后评价。

五个 Agent 怎样协作
----------------------

1. **问题理解 Agent** 把自然语言转换为几何、线弹性方程、材料和边界草稿，并指出孔边等缺项。
2. **求解规划 Agent** 提出 tanh MLP、均匀采样、固定损失、Adam 和坐标自动微分的初始方案。
3. **规范验证 Agent** 检查 ProblemSpec/MethodSpec，研究者补齐孔心和所有自由边牵引条件。
4. **代码构建 Agent** 从验证后的规范确定性导出本地训练与测试脚本。
5. **诊断评估 Agent** 读取 RunArtifact，定位尺度、动量残差和孔边牵引问题，并把建议返回下一轮。

第一次运行：SI 制下的失败
-----------------------------

宽度 64、四层网络在 CPU 上运行 10000 步 Adam。最终总损失约
:math:`2.19\times10^{22}`，相对初值只下降约 1.6%，PDE 残差 RMSE 约
:math:`1.71\times10^{10}`。相对 FEM 的位移 L2 达 :math:`3.65\times10^4`。
诊断将运行标为有效但不健康，并提示残差尺度与牵引条件风险。

第二轮：无量纲化
----------------

研究者保持网络和 Adam 设置，仅引入 :math:`L=1` m、:math:`S=10^6` Pa、
:math:`U=SL/E`。三个随机种的位移相对 L2 为 0.758、0.765 和 0.775。数值稳定性得到修复，
但精度目标仍未达到；第二次诊断指出 x 动量和孔边牵引残差仍然偏高。

第三轮：固定大批量 L-BFGS 续训
-------------------------------

从无量纲 Adam checkpoint 暖启动，固定 2048 个内部点和 512 个边界点，运行 260 个
L-BFGS 外层步。三个随机种的位移相对 L2 分别达到 0.0351、0.0413 和 0.0631；seed 0
在移位探针集上为 0.0352，应力相对 L2 为 0.0366，x 动量残差 RMSE 从 0.494 降至 0.113。

这个案例说明，Agent 提供的是可审计的草稿、检查、代码和诊断证据，研究者仍负责补齐物理条件、
判断诊断建议并设计修复实验。正式移入“已复现”状态前，还需把 FEM 参考、三随机种配置、
checkpoint、RunArtifact、指标和图像一起纳入仓库或可追溯发布包。
