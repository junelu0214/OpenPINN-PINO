周期 Poisson 参数族：损失与微分方式比较
========================================

.. admonition:: 结果状态：预印本结果

   本页数字来自随项目提供的 OpenPINN/PINO 预印本第 5.2 节。当前仓库已有 FNO 训练入口和
   二维 Poisson 演示，但尚未提交本页 32 个训练 forcing、16 个测试 forcing 的完整产物。

问题与学习目标
--------------

在周期区域 :math:`[0,2\pi)^2` 上学习参数族

.. math::

   -\Delta u=f, \qquad f\mapsto u.

每个实例由一至四阶 Fourier 谐波制造零均值参考解，并用精确负 Laplacian 生成 forcing。
FNO 从 32 个训练 forcing 学习映射，在 16 个独立 forcing 上评价。

为什么需要两个误差
------------------

仅有 Poisson 物理残差时，:math:`u` 与 :math:`u+C` 同时满足方程。原始相对 L2 会惩罚
自由的加性常数；均值自由相对 L2 则逐实例减去空间均值，更直接评价场的形状。

受控比较
--------

共享设置为 ``32×32`` 网格、宽度 24、三层、10 个 Fourier modes，以及学习率
``3e-3`` 的 1500 步 Adam。

.. list-table::
   :header-rows: 1

   * - 配方
     - 相对基线的唯一变化
     - 平均相对 L2
     - 平均均值自由相对 L2
   * - Op-B
     - 物理损失、有限差分导数
     - :math:`1.48\times10^{-1}`
     - :math:`3.89\times10^{-2}`
   * - Op-L
     - 混合物理与数据损失；每个实例 16 个观测节点
     - :math:`4.04\times10^{-2}`
     - :math:`3.99\times10^{-2}`
   * - Op-D
     - 用谱微分替换有限差分
     - :math:`4.28\times10^{-2}`
     - :math:`1.23\times10^{-2}`

结果解读
--------

Op-L 主要修正自由加性常数，因此原始误差下降而均值自由误差基本不变。Op-D 同时改善两项，
特别是均值自由误差，说明谱微分在这个周期、光滑、规则网格问题上更准确地约束了解的形状。
这一结论不能外推到非周期边界、非光滑场或非结构网格。

:doc:`08_operator_hybrid` 展示混合损失的 smoke。正式复现本页还需补齐参数族数据生成、
共享测试集、逐实例指标和三组配置归档。
