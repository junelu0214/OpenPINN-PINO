质量、复现与问题排查
====================

这里集中管理运行可信度、结果复现、常见问题和版本变化。遇到问题时先区分代码链路是否可运行，
再判断数值结果是否可信；短 smoke 成功不等于模型已经收敛。

质量验证
--------

:doc:`validation` 说明规范验证、运行状态、有限值检查、参考场比较和不能宣称的结论。

结果复现
--------

:doc:`reproducibility` 说明随机种子、配对实验、均值与样本标准差，以及正式结果需要保存的配置、
硬件、时间、指标和失败记录。

常见问题
--------

:doc:`faq` 汇总安装、路径、几何、单位、训练不稳定、参考数据和网页操作问题。

版本变化
--------

:doc:`changelog` 记录公开接口、配置器、算例和方法实现的变化。复现实验时应同时固定提交版本。
