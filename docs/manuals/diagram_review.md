# 双说明书图示：按读者任务走查

日期：2026-10-12。此次是作者切换读者角色的文档走查，不是真实用户研究；
链接和结构由回归测试验证，真实浏览器视觉、打印和键盘呈现仍需人工验收。

## 筛选结果

从初稿 28 张缩减为 10 张：每份 1 张总览 + 4 张正文图。
只有能帮助选择入口、看清重要依赖或避免关键误解的图才保留。
删除安装、图片导入、DXF 导入、孔洞操作、方法比较等重复已有步骤列表的图；
不替换需要逐字段查阅的参数表、接口形状表和验收矩阵。

## 以首次使用者身份走查

任务：导入双圆孔区域，设置自己的 PDE 与孔壁条件，生成并运行代码。

1. 总览的“自定义建模与代码生成”打开独立页；核心图指向几何、PDE、边界、训练设置、脚本核对和结果验证。
2. 几何分流图区分直接参数、闭合曲线、图片 / 坐标、DXF；每项进入操作说明。
3. 边界图先提示确认目标边界，再区分值、外法向导数、混合条件和初值，公式与原对照表一致。
4. 结果图按运行状态、原始结果、过程、参考误差和交接分流，不暗示 loss 降低等于精度达标。

发现与修改：

- 初稿的主流程遗漏了选择方法与训练预算的入口，已补上，避免用户从条件设置直接跳到保存。
- 每个导入细步骤都画一图会重复正文，已移除，保留几何入口图负责分流。
- 图片识别不能自动给物理尺寸、网页预览不是求解结果；在主流程和目标正文中保留这些提醒。
- 图标本身与整个卡片共享同一链接；无需精确点中文字，链接也不依赖 JavaScript。

## 以接手维护的开发者身份走查

任务：修改圆孔参数编辑，确保预览、生成脚本和后端边界条件一致。

1. 总览选择网页配置器；其图指向导入状态、函数契约、参数映射和联动回归。
2. 模块图可转到几何、条件、训练及实验职责；树枝明确不是调用先后关系。
3. 方法到组件图说明先产生配置，再创建计算对象；保留 loss composer 不属于七类组件的例外。
4. 验收图按单元、事件、脚本短跑、真实浏览器和独立参考分层，不能拿低层通过代替高层证据。

发现与修改：

- 初稿把“预览”和“代码生成”串成步骤，容易理解成代码由预览求解结果生成；已改为共享设置下的两个分支。
- 校正调用方向为 updateCode 调用 generatedProblemLines，避免图中箭头暗示反向调用。
- 模块图不冒充逐函数调用图；原详细调用文本折叠保留以便核查顺序和特殊路径。
- 移除与详细正文重复的实验执行、训练单步、扩展任务等图，不增大接手者阅读负担。

## 可复核的验收

### 总框架图修订

继续走查发现：六分支任务地图只能告诉读者“去哪章”，不能解释“软件怎样工作”。
因此两份说明书开头改为真正的 SVG 总流程图，章节目录降为图后的折叠辅助导航。

- 使用者：安装 → 内置 / 自定义分流 → 几何、PDE、边界 → 训练设置 → 生成脚本 → 本地运行 → 判断结果；未达标 / 报错返回修改。
- 开发者：网页生成脚本与 Python / CLI 两类入口汇合到配置校验；Experiment 组装三个对象分支，汇合到 Trainer，再评价、输出。
- 预览没有通向训练的箭头，避免误认为示例场是训练数据；可选外部参考与 solve 后处理在图下注释，不画成必经步骤。
- 图仅展示主流程，训练预算调整也可回到对应设置，并非所有问题都要求重建几何。
- SVG 节点可点击，边包含起点 / 终点标识，测试校验目标和连接有效；独立版链接只用本地锚点。

- `scripts/build_docs.py`：生成独立版、执行标记示例、Sphinx 构建、更新 ZIP。
- `tests/js/manual_diagrams.test.cjs`：两份总览、所有图节点目标、网站 / 独立版一致性、本地原生链接及响应式样式规则。
- `tests/js/manual_pages.test.cjs`：保留 6 个真正的子页、侧栏定位、正文覆盖和跨页链接。
- 原链接颜色、导航测试继续执行；不得因新增图形恢复 visited 紫色。
- DOM 与样式规则检查不等于真实浏览器视觉验收；本次不声称完成该项或正式训练精度验证。
